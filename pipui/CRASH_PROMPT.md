# پرامنت کرش → رفع باگ

هر بار اپ کرش کرد، متن زیر را کپی کن، پر کن و بفرست. من می‌خوانم، علت را پیدا می‌کنم و
فقط **سمت پلاگین** را دست می‌زنم (مسیر مجاز: `/storage/emulated/0/apk/ghostideplugins-main/...`).

---

## 📋 تک‌کپی: این را بفرست

````text
اپ کرش کرد. لاگ کرش کامل اینجاست:

<کل متن کرش را همین‌جا پیست کن>

پلاگین: <اسم پوشهٔ پلاگین، مثلا pipui / python / rust>
مشکل از کجاست؟ اگر می‌دانی بگو، وگرنه خودت از استک‌تریس پیدا کن.

دستورهای من:
1. اول لاگ و فایل‌های پلاگین را بخوان و علت ریشه‌ای را بگو.
2. فقط داخل پوشهٔ پلاگین فایل‌ها را عوض کن. سمت اپ (GhostIdes) فقط خواندنی است.
3. بعد از تغییر، پلاگین را بیلد کن و خروجی .gpl را بساز.
4. اگر چیزی از سمت اپ باید درست شود، فقط گزارشش را بده — خودت آن را تغییر نده.
````

---

## ✅ چک‌لیست قبل از فرستادن پرامنت

اگر این‌ها را پر کنی، یک‌باره درست می‌شود:

- [ ] کل استک‌تریس، نه فقط خط اول
- [ ] نام و نسخهٔ اپ + مدل گوشی + نسخهٔ اندروید
- [ ] مسیر فایلی که فکر می‌کنی مقصر است (اگر می‌دانی)
- [ ] وضعیت قبل از کرش: «دومین بار باز کردم»، «چرخاندم گوشی»، «روتیشن دادم»، «دکمهٔ X را زدم»
- [ ] آیا با یک پلاگین دیگر هم کرش می‌کند؟ (تک‌پلاگینی است یا عمومی؟)

## 🧠 چیزی که از کرش‌های قبلی یاد گرفتیم

| نشانه | معمولاً یعنی |
|---|---|
| `The specified child already has a parent` | `createView()` یک view از قبل attach‌شده را برگردانده — **همیشه قبل از تحویل، `removeView` کن** |
| `NullPointerException` در `activity.…` | پنل بعد از مرگ/تغییر Activity صدا زده شده — `isFinishing()`/`isDestroyed()` را چک کن |
| `IllegalStateException` در `FragmentManager` | دوبار `show()` بدون `remove()` قبلی (transaction باید `commitNow` باشد) |
| `Resources$NotFoundException` از `R.layout` | view با context خود پلاگین inflate نشده — `LayoutInflater.from(pluginContext).cloneInContext(...)` |
| `OutOfMemoryError` / UI فریز | view سنگین در `createView()` ساخته شده؛ باید lazy باشد |

## 🔁 روال کار من بعد از گرفتن پرامنت

1. خواندن لاگ و پیدا کردن خط دقیق کرش
2. باز کردن فایل‌های پلاگین و خواندن مسیر کرش
3. گفتن علت در ۱–۳ جمله **قبل** از هر تغییری
4. اعمال کمترین تغییر ممکن، فقط در پوشهٔ پلاگین
5. بیلد: `bash build.sh` و تحویل `.gpl`
6. اگر ریشه در اپ بود: گزارش + راه‌حل، بدون دست زدن به کد اپ
